## Findings and Fixes

### Medium — interrupted Session 21 implementation was not type-safe

Normalized the optional profile banner URL before passing it to `next/image`,
then revalidated the build. Also corrected failed-banner spacing on ChannelPage
and added URL-keyed failed-avatar fallback on the watch page.

### Medium — unsupported external image hosts could fail under next/image

Added `isNextImageSafeUrl`: configured Google/Blob hosts use optimized delivery,
while other valid HTTPS URLs retain native image rendering. Repeating image
surfaces use URL-keyed failure sets so one broken image does not hide unrelated
items.

### Medium — desktop portrait watch layout underused horizontal space

Moved the player and details into a responsive desktop grid. The player is
left-aligned and sticky within the existing app scroll viewport; the Up Next
rail stays on the right with its own bounded scroll. Mobile/tablet widths stack
back into normal document flow.

### High user-impact — settings button appeared non-functional

Removed the clipping ancestor around the control row. Added explicit popup
state behavior, Escape dismissal with focus restoration, outside-pointer
closure, accurate labeled-group semantics, and portrait-first control sizing
that omits the volume slider before metadata is known.
