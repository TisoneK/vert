# UI Interaction Review — 2026-08-05

## Executive Summary

Three user-reported UI issues were reviewed and fixed as separate sequential
sessions: missing scroll affordances, progress indicators escaping their tracks,
and non-functional video controls. The fixes were kept local to shared scrollbar
CSS, progress primitives, and the video player.

## Baseline Health

Before and after the changes:

- `npx tsc --noEmit`: passed.
- `npx eslint .`: passed with 0 errors and 19 existing warnings.
- `npx next build`: passed; all 47 routes generated.
- No test runner is configured in this repository.

## Session 15 — Scroll containers

The direct cause was explicit hiding of scrollbars in `globals.css`: the main
app viewport used zero-width WebKit scrollbars and `scrollbar-width: none`, and
horizontal shelves used zero-height/hidden scrollbars. Both now use thin,
themed tracks/thumbs in light and dark mode. Overflow behavior itself was not
changed. Native overlay-scrollbar platforms may still hide tracks according to
OS policy; the existing fade hint remains as a secondary affordance.

Commit: `33a87c5` (`fix(ui): restore visible scroll affordances`).

## Session 16 — Progress containment

The shared Radix progress wrapper used raw values in its transform. Values are
now finite and clamped to the configured positive max, and the bounded value is
passed to Radix so accessibility state matches the rendered indicator. The video
player bounds its computed percentage, clamps pointer-derived seek positions, and
clips the seek track with rounded overflow.

Commit: `35a6bc6` (`fix(ui): contain progress indicators`).

## Session 17 — Video controls

The invisible controls layer previously remained a hit target at zero opacity,
which could block mobile taps. The centered pause layer was rendered above the
bottom bar, intercepting clicks while playing. Hidden controls now disable pointer
input; center play/pause affordances use button targets; the pause layer's wrapper
passes pointer input through so the bottom bar remains reachable. The seek track
now exposes slider semantics and Arrow/Home/End keyboard seeking. Container-level
shortcuts ignore events originating inside interactive controls, preventing Space
from toggling playback twice.

Commit: `4a90f2d` (`fix(video): restore player control interactions`).
